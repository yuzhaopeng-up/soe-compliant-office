# 5G专网客户分析报告

---

## 一、执行摘要

本报告聚焦5G专网政企客户运营分析。关键发现：
- 5G专网在网客户 28 家，较上季度新增 6 家
- 月度收入 312 万元，同比增长 45%，环比增长 8%
- 客户覆盖制造（12家）、能源（7家）、交通（5家）、医疗（4家）四大行业
- 平均合同周期 24 个月，续约率 89%
- 标杆案例 3 个，可复用推广至同类行业

**核心结论**：5G专网是政企收入增长引擎，制造行业渗透率最高；需加速能源和交通行业复制；续约率健康，但需关注合同到期集中期。
