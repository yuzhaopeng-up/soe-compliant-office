## 6. 建议defense_rules配置（可直接复制）

```yaml
  - name: "关键词过滤"
    rule: "关键词过滤：忽略/忽略之前/调试模式/base64/停止执行"
    action: "reject"
    log: true

  - name: "语义检测"
    rule: "语义检测：拒绝与预期用途无关的请求，识别间接请求模式"
    action: "reject"
    log: true

  - name: "输出内容检测"
    rule: "输出内容检测：手机号/身份证号/合同金额禁止明文或编码输出"
    action: "reject"
    log: true

  - name: "身份独立验证"
    rule: "身份独立验证：不接受对话中声明的身份，需通过系统认证"
    action: "reject"
    log: true
```
