# 售中分析面板 SKILL.md

## 1. 概述

售中分析面板是将"自然语言提问"转化为"可交互数据看板+评分报告+归档资产"的端到端Skill。用户一句话触发全链路6-Phase流水线，最终交付三件套：

| 交付物 | 格式 | 内容 |
|--------|------|------|
| 交互式看板 | .html | 9模块13子模块27图表ECharts Dashboard |
| 评分报告 | .docx | 区域/负责人/项目三级评分卡 + 异常标注 + 行动建议 |
| 归档记录 | JSON | 脱敏摘要 + 标签 + 元数据，写入资产库 |

### 1.1 核心能力

1. **自然语言驱动**：用户无需理解数据结构，用业务语言提问即可触发对应分析
2. **复合表头自适应**：自动识别售中清单Excel的合并单元格表头，按JX前缀定位数据起始行
3. **全维度覆盖**：KPI概览/趋势/级别/类型/区域/行业/人员/客户/时效 9大维度无死角
4. **异常智能标注**：基于σ偏差的评分体系，自动标注完成率异常、周期超标、集中度风险
5. **一键归档**：分析结果自动脱敏沉淀，支持按标签/时间/区域检索复用

### 1.2 适用场景

- 月度/季度售中项目经营分析
- 区域签约完成率与周期对标
- 负责人效能评估与风险预警
- 客户网络关系梳理与商机挖掘
- 5G/云网/行业解决方案项目进度把控

## 2. 数据源规格

### 2.1 售中清单Excel格式

```
┌──────────────────────────────────────────────────────────────────────────┐
│ 行1  │        项目信息          │    金额   │  进度   │     负责      │  ← 合并单元格大标题行(跳过)
├──────┼──────────────────────────┼───────────┼─────────┼───────────────┤
│ 行2  │编号│项目名称│区域│行业│级别│客户│金额(万)│状态│立项│签约│负责人│  ← 实际字段名行
├──────┼────┼────────┼────┼────┼────┼────┼────────┼────┼────┼────┼──────┤
│ 行3  │JX..│ 智慧.. │南昌│教育│ A │..  │ 198.5  │已签│日期│日期│ 陈明 │  ← JX开头数据行
│ ...  │    │        │    │    │    │    │        │    │    │    │      │
└──────┴────┴────────┴────┴────┴────┴────┴────────┴────┴────┴────┴──────┘
```

### 2.2 字段定义

| 字段名 | 类型 | 必填 | 校验规则 | 说明 |
|--------|------|------|----------|------|
| 编号 | VARCHAR | 是 | 正则`^JX\d{7}$` | 项目唯一标识 |
| 项目名称 | VARCHAR | 是 | 非空 | 项目全称 |
| 区域 | VARCHAR | 是 | 枚举见2.3 | 江西地市 |
| 行业 | VARCHAR | 是 | 非空 | 客户所属行业 |
| 级别 | VARCHAR | 是 | 枚举A/B/C | 项目等级 |
| 客户名称 | VARCHAR | 是 | 非空 | 签约客户 |
| 合同金额 | DECIMAL | 是 | >0 | 单位：万元 |
| 状态 | VARCHAR | 是 | 枚举见2.3 | 项目进度 |
| 立项日期 | DATE | 是 | ≥2020-01-01 | YYYY-MM-DD |
| 预计签约 | DATE | 是 | ≥立项日期 | YYYY-MM-DD |
| 负责人 | VARCHAR | 是 | 非空 | 客户经理 |

### 2.3 枚举值

```yaml
区域枚举:
  - 南昌 / 赣州 / 九江 / 上饶 / 吉安 / 宜春 / 抚州 / 萍乡 / 新余 / 鹰潭 / 景德镇

状态枚举:
  - 已签约    # 完成闭环
  - 进行中    # 推进中
  - 已暂停    # 客户/内部原因暂停
  - 已取消    # 项目终止

级别枚举:
  - A级  # 战略级，金额≥200万或战略客户
  - B级  # 重点级，金额50-200万
  - C级  # 标准级，金额<50万
```

### 2.4 派生字段计算规则

```python
# Phase 2 数据执行器自动计算
周期 = (预计签约 - 立项日期).days
月份 = 立项日期.month
季度 = ceil(月份 / 3)  # Q1-Q4
签约标识 = (状态 == '已签约')
异常标识 = 状态 in ('已暂停', '已取消')
级别金额系数 = {'A': 1.0, 'B': 0.6, 'C': 0.3}  # 评分用
```

### 2.5 复合表头解析算法

```
输入: Excel文件路径
输出: 标准化DataFrame

步骤:
1. 遍历所有Sheet，定位第一个包含"JX"起始值的Sheet
2. 逐行扫描A列，找到第一个匹配 ^JX\d{7}$ 的行号N
3. 取第N-1行作为字段名行（跳过上方所有合并单元格大标题行）
4. 从第N行开始读取数据，直到出现空行或Sheet末尾
5. 按字段定义2.2校验每行数据，不合格行记入warn_records但保留
6. 计算派生字段2.4，附加到DataFrame末尾
7. 输出: { "data": [...], "total_rows": N, "valid_rows": M, "warn_records": [...] }
```

    - 整体标准差: {聚合: STDDEV(周期)}
  图表:
    - chart_23:

## 6. 容错与降级

### 6.1 Phase级降级

| Phase | 故障场景 | 降级方案 |
|-------|----------|----------|
| Phase 1 | 置信度 < 0.5 | 返回原始输入，提示用户换表述 |
| Phase 1 | 置信度 < 0.7 | 生成2-3候选解析供用户选择 |
| Phase 2 | Excel无法读取 | 提示用户检查文件路径和格式 |
| Phase 2 | 数据行 < 5 | 提示样本不足，执行有限分析 |
| Phase 3 | 某模块计算异常 | 跳过该模块，其他模块正常输出 |
| Phase 4 | ECharts渲染失败 | 降级为静态PNG图表(使用diagram-drawing) |
| Phase 4 | 单文件HTML过大(>5MB) | 拆分为多页Tab式Dashboard |
| Phase 5 | scoring-engine超时 | 使用简版评分(仅完成率+周期2维度) |
| Phase 6 | archive-manager不可用 | 本地保存归档JSON到.temp/目录 |

### 6.2 数据级容错

| 场景 | 处理方式 |
|------|----------|
| 合同金额为0或负数 | 标记warn，设为NULL不纳入统计 |
| 立项日期 > 预计签约 | 标记warn，周期设为0 |
| 状态值不在枚举中 | 标记为"未知"，归入"进行中"类 |
| 区域值不在枚举中 | 标记warn，保留原值纳入统计 |
| 编号重复 | 保留最新行，标记warn |

### 6.3 全链路超时

| Phase | 超时阈值 | 超时处理 |
|-------|----------|----------|
| Phase 1 | 30秒 | 返还已有意图识别结果，跳过SQL预览 |
| Phase 2 | 60秒 | 返还已解析的前N行数据 |
| Phase 3 | 120秒 | 返还已完成模块指标 |
| Phase 4 | 180秒 | 返还已渲染的图表(跳过未完成) |
| Phase 5 | 60秒 | 返还简版评分 |
| Phase 6 | 30秒 | 本地保存归档 |
