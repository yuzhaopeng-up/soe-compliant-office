**面向中国央国企的 AI Agent Skill 体系 —— 合规内建、审计留痕、国标适配。**

这不是又一套通用办公自动化工具。每个 Skill 围绕**央国企必需而民企工具忽视的三大原则**设计：

| 原则 | 含义 | 为什么央国企需要 |
|------|------|----------------|
| **合规内建** | 合规逻辑在执行过程中运行，而非事后补检 | 三重一大、穿透式监管、首席合规官 — 合规是生命线，不是功能 |
| **审计留痕** | 每次操作自动记录谁/何时/做了什么 | 表决记录10年+保存、全级次全要素追溯、巡视整改可查 |
| **国标适配** | GB/T 9704、DA/T 归档、国资委报表格式内置 | 红头文件格式、国资委月报模板、电子归档规范 |

## 快速开始

```bash
# 克隆仓库
git clone https://github.com/yuzhaopeng-up/soe-compliant-office.git

# 任意 Skill 可独立使用 — 复制到 TeleAgent 技能目录
cp -r skills/document/pptx ~/.config/TeleAgent/skills/pptx

# 或直接使用 Python 引擎
cd skills/document/contract-review
pip install -r requirements.txt
python demo.py
```

### 生成 GB/T 9704 合规公文

```python
from docx.engine import SkillEngine

engine = SkillEngine()
result = engine.run({
    "action": "create_official_document",
    "doc_type": "请示",           # 15种法定文种之一
    "issuer": "XX集团",
    "recipient": "国务院国资委",
    "classification": "秘密",      # 秘密/机密/绝密
    "urgency": "加急",            # 特急/加急
    "body": "关于XXX的请示..."
})
```

### 三层合规合同审查

```python
from contract_review.engine import SkillEngine

engine = SkillEngine()
result = engine.run({
    "action": "review",
    "contract_path": "procurement_contract.docx",
    "review_layers": ["basic", "business", "legal"],
    "risk_threshold": "MEDIUM"    # LOW/MEDIUM/HIGH/CRITICAL
})
# 返回：结构化问题列表、风险等级、Mermaid业务流程图
```

## 央国企 vs 民企：为什么需要这套仓库

| 能力 | 通用 AI 办公工具 | 央国企合规办公 |
|------|----------------|--------------|
| 文档格式 | 自由格式 | GB/T 9704 15种法定文种 |
| 合同审查 | 仅语法检查 | 三层合规审查 + 风险分级 |
| 审批流程 | 单步审批 | 多级串行（业务→法务→合规→审计） |
| 数据安全 | 云优先 | 本地优先，自动脱敏，密级标注 |
| 审计留痕 | 无 | 每次操作记录谁/何时/做了什么 |
| 会议纪要 | 通用模板 | 党委会/董事会/总经理办公会专用模板 |
| 打印 | 直接打印 | 预览预检，安全打印策略 |
| 国标适配 | 无 | GB/T 9704、DA/T归档、国资委报表格式 |

## 贡献指南

详见 [CONTRIBUTING.md](./CONTRIBUTING.md)。核心规则：
- 所有 Skill 必须在 SKILL.md frontmatter 中声明 `soe_relevance`（1-5）
- soe_relevance >= 4 的 Skill 必须包含"央国企特色"章节
- Python 引擎类必须在入口/出口调用审计日志
- 包含个人或业务数据的输出必须脱敏
