# 风险等级规则与敏感内容识别

## 风险等级评估规则

### L1 🟢 低风险 - 只读查询

- 查询客户基本信息（不含敏感字段）
- 查看工单列表
- 查询系统状态
- 生成内部报表

### L2 🔵 中低风险 - 内部消息通知

- 向内部群发送不含敏感信息的消息
- 内部工作提醒
- 状态变更通知
- 日程提醒

### L3 🟡 中等风险 - 数据修改

- 修改客户非敏感信息（联系方式、备注等）
- 更新工单状态
- 修改个人偏好设置
- 内部数据更正

### L4 🟠 中高风险 - 含敏感信息的群发/外部发送

- 群发包含客户经营信息的消息
- 向外部邮箱发送含业务数据的邮件
- 导出包含客户信息的列表（含姓名/手机号）
- 修改客户关键业务信息（合同金额、有效期）

**触发条件（满足任一即升为L4）：**
- 操作内容包含客户经营数据（交易金额、合同条款、流失风险）
- 发送目标包含外部人员或群发超过5人
- 操作内容包含可识别客户的业务信息

### L5 🔴 极高风险 - 删除/系统命令/外部数据传输

- 删除业务记录
- 删除客户数据
- 执行系统命令
- 向外部系统传输数据
- 批量导出完整客户列表
- 修改系统配置参数

**自动升级规则：**
- 操作类型为"执行系统命令" → 最低L5
- 操作类型为"删除业务记录" + 含敏感信息 → L5
- 操作影响范围超过50人/全部客户 → 升一级（上限L5）
- 操作目标为外部系统/外部邮箱 → 最低L4

## 权限检查规则

| 操作类型 | 最低权限要求 |
|----------|-------------|
| 发送群消息 | msg:send |
| 修改客户数据 | customer:edit |
| 删除业务记录 | ticket:delete |
| 导出业务数据 | customer:export |
| 发送外部邮件 | mail:external |
| 执行系统命令 | system:exec |

权限不足时直接拒绝，不生成审批单，输出：
"当前用户无执行此操作的权限：缺少XXX权限"

## 敏感内容识别模式

扫描 `operation_content`，按以下模式识别并标注 ⚠️：

### 客户经营信息
- 交易金额/月均/合同金额："月均XX万"、"合同金额"、"营收"
- 流失预警："流失风险"、"流失预警"、"客户预警"
- 经营状况："经营困难"、"资金链"、"停产"

### 合同条款
- 合同编号/名称："合同编号"、"HT-"
- 合同金额与期限
- 保密条款相关

### 系统配置参数
- IP地址、端口号
- 数据库连接串
- API密钥/Token
- 管理员账号

### 个人隐私数据
- 手机号：1[3-9]\d{9}
- 身份证号：\d{17}[\dXx]
- 银行卡号
- 邮箱地址（非内部）

## 脱敏规则（归档时使用）

| 数据类型 | 脱敏方式 | 示例 |
|----------|----------|------|
| 手机号 | 保留前3后4 | 138****1234 |
| 身份证号 | 保留前3后4 | 360***********1234 |
| 合同金额 | 保留量级 | XX万 → **万 |
| 客户名称 | 保留行业 | 某制造企业 → 某制造企业 |
| 银行卡号 | 保留后4 | ****1234 |

## 降级执行策略

用户选择[3]降级执行时，按操作类型推荐降级方案：

| 操作类型 | 推荐降级方案 |
|----------|-------------|
| 发送群消息 | 群发→私发（仅发送给直接相关人） |
| 修改客户数据 | 全量修改→增量修改（仅修改非敏感字段） |
| 导出业务数据 | 完整导出→脱敏导出（去除手机号/身份证） |
| 发送外部邮件 | 含附件→不含附件 / 含敏感→脱敏后发送 |
| 删除业务记录 | 删除→归档（标记为已归档而非物理删除） |
| 执行系统命令 | 自动执行→生成命令供人工执行 |
