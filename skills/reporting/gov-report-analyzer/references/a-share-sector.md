## 二、产业链传导路径

### AI+链条

```
上游(算力基座) → 中游(模型平台) → 下游(应用)
光模块/服务器/GPU   大模型/云平台    AI应用/终端
PCB/存储/交换机    数据要素/标注    AI眼镜/机器人
↑最先受益            ↑同步受益       ↑滞后1-2季
传导时滞：1-2周 → 2-4周 → 2-3个月
验证：算力招标量 → API调用量 → 应用DAU
```

### 消费升级链条

```
供给端(制造升级) → 渠道端(体验升级) → 消费端
智能家电/新能源车    新零售/直播电商    服务消费
传导时滞：1-3月 → 即时 → 2-4季度
验证：社零增速 → 服务零售额 → 居民支出结构
```

### 化债+地产链条

```
化债直接受益 → 信贷修复 → 地产企稳 → 经济传导
城商行/AMC      城投平台    地产龙头    建材/家居
↑先受益         ↑滞后1季    ↑滞后2季    ↑滞后3季
```

## 三、历史政策事件板块反应

### 2024年"新质生产力"

| 窗口 | 板块 | 涨幅 | 超额 | 天数 |
|:----:|:----:|:---:|:---:|:----:|
| 03.05-15 | 计算机 | +12.5% | +9.4% | 13 |
| 03.05-15 | 电子 | +8.2% | +5.1% | 9 |

规律：概念首次写入弹性最高，计算机/电子最先反应

### 2025年"适度宽松"重提（12月中央经济工作会议）

| 窗口 | 板块 | 涨幅 | 超额 | 天数 |
|:----:|:----:|:---:|:---:|:----:|
| 12.10-20 | 非银金融 | +10.3% | +7.2% | 10 |
| 12.10-25 | 房地产 | +8.5% | +5.4% | 12 |

规律：14年首次重现重大转向，券商最先反应

### 2025年"以旧换新3000亿"

| 窗口 | 板块 | 涨幅 | 超额 | 天数 |
|:----:|:----:|:---:|:---:|:----:|
| 03.05-20 | 汽车 | +9.2% | +6.2% | 12 |
| 03.05-15 | 家电 | +7.5% | +4.5% | 8 |

规律：有量化金额的信号比纯定性表述更确定

### 核心规律

| 规律 | 说明 |
|------|------|
| 首次效应 | 概念首次写入弹性1.5-3.0x，后续递减 |
| 量化溢价 | 有具体数字比纯定性强30-50% |
| 预期差驱动 | 超出市场预期的转向弹性最大 |
| 龙头溢价 | 二级行业龙头涨幅是非龙头2-3倍 |
| 北向验证 | 3日内北向持续净买入→行情持续性更强 |

## 四、资金流向验证

### T+0~T+20观察窗口

| 窗口 | 指标 | 判断标准 |
|:----:|------|---------|
| T+0~1 | 板块主力净流入 | 全市场前3为确认 |
| T+0~1 | 北向行业净买入 | 外资认可政策方向 |
| T+0~3 | 成交额放大倍数 | >1.5x有效催化，>2.5x强催化 |
| T+0~5 | 龙虎榜机构参与度 | 机构>散户→中长线认可 |
| T+0~10 | 涨停股数/连板高度 | 连板出现→游资接力 |
| T+0~20 | ETF份额变化 | 持续增加→增量资金入场 |

### 真假催化鉴别

| 特征 | 真催化(可持续) | 假催化(脉冲) |
|------|:-----------:|:----------:|
| 龙头走势 | 跳空高开+持续放量 | 高开低走 |
| 板块扩散 | 龙头→二线→扩散 | 仅龙头独涨 |
| 成交额 | 逐日温和放大 | 单日天量后萎缩 |
| 机构行为 | 买入+研报覆盖 | 散户买入为主 |
